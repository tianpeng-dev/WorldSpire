# 后端模块契约

| 模块 | 服务入口 | 当前能力 |
| --- | --- | --- |
| 配置 | `lib/config/env.ts` | Node.js 24 校验、环境变量校验、应用与数据库命令共用加载逻辑 |
| 认证 | `lib/auth/auth.ts`、`identity.ts` | Better Auth 匿名儿童、家长邮箱密码、数据库会话、旧会话升级、数据库限流 |
| 绑定 | `lib/binding/service.ts` | 八位好友码、待确认申请、儿童确认、双方解除、家长儿童列表 |
| 内容 | `lib/content/service.ts` | 统一课程初始化、课程查询、关卡资源契约、Blob 上传接口 |
| 学习 | `lib/learning/service.ts` | 服务端判题、BKT 掌握度、首次掌握时间、会话进度、主力设备检查 |
| 奖励 | `lib/rewards/service.ts` | 事务内更新钱包和同步记录，由业务事件的幂等检查保护 |
| 收藏 | `lib/collection/service.ts` | 事务兑换、余额检查、并发重复兑换保护 |
| 对战 | `lib/battle/service.ts` | AI 对战三回合、服务端判题、按回合胜负结算、事务奖励 |
| 报告 | `lib/report/service.ts` | 实际时长、答题正确率、首次掌握词数、规则摘要及外部摘要接口 |
| 通知 | `lib/push/service.ts` | 实际站内队列写入、所属账号查询和已读更新 |
| 同步 | `lib/db/sync.ts`、`sync-records.ts` | 逐项确认、事务收据、实体版本、儿童下行游标 |
| 定时任务 | `lib/cron/service.ts` | Bearer 鉴权、周期唯一执行、事务工作、失败及重试记录 |

亲子异步对战、设备推送发送器等尚未实现的能力返回 `501`。外部摘要或资源存储缺少必需配置时，直接调用对应服务接口返回 `503`。周报任务允许使用 PRD 中的规则摘要，并通过 `summary_source` 保存来源；已配置的摘要服务发生外部异常时，记录实际异常并使用规则摘要。

报告没有评估依据的听说能力和成就列表返回空列表。未登记的排行返回 `null`。通知成功写入 `notifications` 后才返回 `queued: true`。数据库队列记录代表站内通知可查询；设备推送成功需要实际发送器及送达结果。

## 数据变更

儿童业务写入先锁定儿童档案，再更新关联实体。答题记录、掌握度、钱包、关卡状态与同步记录使用同一个 PostgreSQL 事务。通关结算检查已完成状态，收藏兑换检查既有收藏，对战结算检查已结算状态；重复请求不会再次增加奖励或扣除余额。

好友码申请按家长限流，每分钟最多 10 次；认证入口使用 Better Auth 的数据库限流。角色由服务端设置，客户端无法通过注册字段指定角色。浏览器退出删除当前数据库会话。旧 Cookie 升级同时检查签名、账号角色与儿童档案归属。

## 同步字段

请求继续使用 `deviceId`、`childProfileId`、`items` 和 `lastSyncVersion`。每个项目继续使用原有 `id`、`entity`、`entityId`、`op`、`version`、`deviceId`、`createdAt` 和 `payload` 字段。

- `version` 是实体版本，用于检测过期或冲突；服务端按照实际变更递增实体版本。
- `lastSyncVersion` 和 `serverVersion` 是当前儿童的下行游标，与实体版本独立。
- 每个服务端项目包含 `cursor`，按儿童在事务内递增；一次响应最多返回 500 条，下行仍有数据时 `hasMore` 为 `true`。
- `acknowledgements` 按原队列项目 `id` 返回 `accepted` 或 `rejected`，失败时提供 `error`、`statusCode` 和可用的校验详情。
- `accepted` 数量和 `rejected` 实体标识列表保留兼容用途。调用端使用 `acknowledgements` 中的队列项目标识更新状态。
- 队列收据包含请求指纹。相同项目重试返回确认；相同项目标识携带不同内容返回冲突。
- 客户端提交 `attempts` 时，服务端依据 `optionId` 判题并计算掌握度与奖励。`sessions` 支持创建和完成命令，完成时检查真实答题记录。直接覆盖掌握度或关卡状态返回 `501`。

本地客户端为每个儿童分别保存下行游标。失败项目保留在本地队列中；成功项目只确认对应的队列项目标识。同一实体的其他待同步版本保持原有状态。

## 内容与统计

初始化内容使用既有水果王国课程、4 个关卡和 9 道题目，保留原有标识。当前内容覆盖图片选择；其余 PRD 题型已建立数据类型与数据库约束。课程生产、音频素材、完整的离线题包学习体验、亲子异步对战和完整家长业务页面仍需要对应业务实现。

每日统计、连续学习天数和周报周期按 UTC 计算。新增词汇使用 `first_mastered_at`，仅在掌握度首次达到 0.7 时登记。已有记录缺少首次掌握日期时，不推算其历史新增日期。累计词汇保留原有档案值，并在之后首次达到标准时更新。

## 验证边界

自动化集成测试通过真实 PostgreSQL 16、真实 Next.js HTTP 服务和真实 Better Auth 会话执行。测试中的数据库异常由独立数据库内的触发器制造，并查询数据库验证事务结果。单元测试覆盖纯计算和本地队列确认逻辑。

外部服务凭据、云端部署、浏览器 IndexedDB 持久化、真实设备推送和移动设备运行状态需要各自环境进行验证。本机数据库和 HTTP 测试通过的结果不代表这些环境已经通过验证。
