## 文件使用

`人教版英语（精通）三年级下册.pdf` 为全书图片PDF，每一页保留服务器提供的原始JPEG数据和图片比例。

`pages/001.jpg` 至 `pages/102.jpg` 为原始页面图片。文件编号与PDF页序、官方阅读器页序一致，教材正文的印刷页码可能不同。

`manifest.json` 保存教材来源、下载时间、逐页来源地址、图片尺寸、文件大小和SHA-256。

`sources/` 保存官方阅读页面及阅读配置。`verification.json` 保存完整页数、图片解码、文件校验与PDF内嵌图片比对结果。

`人教版英语（精通）三年级下册_原始页面.zip` 包含原始页面图片、来源清单和校验记录。

## 后续题库处理

PDF没有正文文字层。整理题库时需要识别页面文字，并结合原始图片核对单词、课文、活动内容与教材印刷页码。
