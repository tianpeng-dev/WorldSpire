## 文件使用

`人教版英语（精通）三年级上册.pdf` 为全书图片PDF。每一页完整保留服务器提供的大图JPEG数据和图片比例，便于离线阅读及后续识别教材文字。

`pages/001.jpg` 至 `pages/104.jpg` 为原始页面图片。文件编号与PDF页序、官方阅读器页序一致。教材正文中印刷的页码与文件编号可能不同。

`manifest.json` 保存书名、来源、下载时间以及每一页的来源地址、图片尺寸、文件大小和SHA-256，便于后续题目追溯到教材页面。

`sources/` 保存官方阅读页面及阅读配置。`verification.json` 保存完整页数、图片解码、文件校验与PDF内嵌图片比对结果。

`人教版英语（精通）三年级上册_原始页面.zip` 包含原始页面图片、来源清单和校验记录，便于传递素材。

## 后续题库处理

PDF没有正文文字层。后续整理题库需要识别页面文字，并结合原始图片核对单词、课文、活动内容与教材印刷页码。
